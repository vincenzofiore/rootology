# Brand

Drawn for Rootology as plain SVG (no generated or third-party artwork).

- `rootology-icon.svg` (and `rootology-icon-512.png`): the app's icon, a sprout above the soil line with its
  roots below. In the app: `META-INF/resources/icons/` holds the favicon (SVG and 32 px PNG) and the
  180 px home-screen icon on a full square (iOS fills transparency with black). The PNGs are rendered from
  the SVGs with macOS Quick Look (`qlmanage -t -s <size>`).
- `mascot-radish.svg` (and `mascot-radish-1024.png`): the radish mascot, kept for promotion.

The Apache-2.0 licence of the repository grants no trademark rights (its section 6): the name and these marks
identify Rootology.
